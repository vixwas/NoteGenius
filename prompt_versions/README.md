# NoteGenius Prompt Versions

This directory stores prompt versions, final prompts,
test samples, and testing records for Quiz and Flashcards.

## Quiz
- v1.txt: Initial quiz prompt.
- v2.txt: Historical version (pending recovery).
- v3.txt: Current quiz generation prompt.
- final.txt: Approved final quiz prompt.
- test_results.md: Quiz testing records.

## Flashcards
- v1.txt: Initial flashcard prompt (pending recovery).
- v2.txt: Intermediate flashcard prompt (pending recovery).
- v3.txt: Current flashcard generation prompt.
- final.txt: Approved final flashcard prompt.
- test_results.md: Flashcard testing records.

## Test Samples
- sample_inputs.txt: Sample study materials and configurations.
- edge_cases.md: Edge-case test scenarios.
- expected_output.md: Expected response structures.

## Notes
Historical prompt versions should be preserved accurately.
Do not replace missing historical prompts with invented content.
