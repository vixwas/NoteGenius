Machine Learning

Machine Learning is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

There are three major types of Machine Learning:

1. Supervised Learning:
The model learns from labelled data. Each training example contains input features and a known output. Common applications include email spam detection, house price prediction and image classification.

2. Unsupervised Learning:
The model learns from unlabelled data and identifies hidden patterns or structures. Clustering and dimensionality reduction are common techniques.

3. Reinforcement Learning:
An agent learns by interacting with an environment. It receives rewards or penalties based on its actions and improves its strategy over time.

Overfitting occurs when a model learns the training data too closely, including noise, and performs poorly on unseen data. Underfitting occurs when a model is too simple to capture the underlying patterns.

Model evaluation is important for measuring performance. Classification models can be evaluated using accuracy, precision, recall and F1-score. Regression models commonly use Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
