# Machine Learning

## Quick Overview
Machine Learning is a branch of Artificial Intelligence that allows computers to learn patterns from data and make predictions or decisions without explicit programming for every individual task.

## Core Concepts
* **Supervised Learning:** The model learns from labeled data, where each training example includes input features and a known output.
* **Unsupervised Learning:** The model learns from unlabeled data to identify hidden patterns or structures.
* **Reinforcement Learning:** An agent learns by interacting with an environment, receiving rewards or penalties based on its actions to improve its strategy over time.

## Essential Details
* **Overfitting:** Occurs when a model learns the training data too closely (including noise) and performs poorly on unseen data.
* **Underfitting:** Occurs when a model is too simple to capture the underlying patterns in the data.
* **Model Evaluation:** Essential for measuring performance using specific metrics tailored to the type of model.

## Formulas / Algorithms / Processes
* **Classification Model Evaluation Metrics:** Accuracy, precision, recall, and F1-score.
* **Regression Model Evaluation Metrics:** Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).

## Connections and Comparisons
* **Types of Learning Compared:** 
  * *Supervised* uses labeled data and known outputs.
  * *Unsupervised* uses unlabeled data to find hidden structures (e.g., clustering, dimensionality reduction).
  * *Reinforcement* uses trial-and-error interaction with an environment via rewards and penalties.
* **Model Fitting Issues:** *Overfitting* (excessive complexity/noise learning) and *underfitting* (insufficient complexity) represent opposite extremes in model training performance.

## Remember These Points
* Machine Learning enables data-driven predictions without explicit programming.
* The three types of ML are Supervised, Unsupervised, and Reinforcement Learning.
* Supervised learning examples: email spam detection, house price prediction, image classification.
* Unsupervised learning techniques: clustering, dimensionality reduction.
* Overfitting hurts generalization on unseen data; underfitting fails to capture underlying patterns.
* Evaluation metrics differ by task: classification uses accuracy, precision, recall, F1-score; regression uses MAE and RMSE.

## Final Summary
Machine Learning is a core branch of Artificial Intelligence divided into supervised, unsupervised, and reinforcement learning paradigms, each addressing data differently to make predictions or decisions. Successful application requires balancing model complexity to avoid overfitting or underfitting, followed by rigorous evaluation using specific classification or regression metrics to ensure strong performance on unseen data.
